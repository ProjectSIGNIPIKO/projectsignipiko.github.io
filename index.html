About Us

PROJECT SIGNIPIKO is a miniature model for an IoT-based predictive maintenance system designed for monitoring road anomalies and hazard conditions, aiming for real-time updates. The project aims to engineer alternative solutions for monitoring since traditional road monitoring relies on manual inspections, which are usually delayed, or optical cameras that are expensive and consume massive network bandwidth. PROJECT SIGNIPIKO resolves this by embedding low-cost piezoelectric sensors directly into the road surface.

The piezo sensors capture the mechanical strain of passing vehicles and convert physical strain into voltage spikes that can be measured via electrical signals. Instead of transmitting large volumes of raw data into the cloud, the system uses edge computing through the ESP32 embedded controller board. The software performs calculations on the input wave voltages, using rate-of-change logic to identify whether the smooth low-frequency rolling is from normal vehicular activity or a high-frequency voltage spike due to contact between a tire and a pothole. In actual scenario implementation, when an anomaly in the signal is monitored, it will alert LGUs. This allows for shifting the manual inspection/patching to preventive and data-driven maintenance.
